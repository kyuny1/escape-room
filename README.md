# 역사 방탈출: 생활 기록 복원 작전

GitHub와 Vercel만으로 배포할 수 있는 정적 HTML 웹앱입니다. Firebase, Firestore, 서버, API 키 설정은 필요하지 않습니다.

## 파일
- `index.html`: 게임 화면, 30개 역사 퀴즈, 개인 점수 처리
- `vercel.json`: Vercel 정적 배포 설정

## 1. GitHub → Vercel 배포
1. [Vercel](https://vercel.com/)에 로그인합니다.
2. **Add New → Project**에서 GitHub 저장소 `kyuny1/escape-room`를 Import합니다.
3. Framework Preset은 **Other**로 선택합니다.
4. 별도 Build Command나 Output Directory는 지정하지 않고 Deploy를 실행합니다.
5. 이후 `main` 브랜치에 커밋하면 Vercel이 자동으로 다시 배포합니다.

## 2. 점수와 저장 방식
- 총 30문제이며 정답당 10점입니다.
- 별명을 입력하면 퀴즈를 시작합니다.
- 점수와 진행 상황은 해당 브라우저의 `localStorage`에 저장됩니다.
- 같은 브라우저에서 같은 별명을 사용하면 진행 기록을 이어갈 수 있습니다.
- 기록은 다른 기기나 다른 브라우저와 공유되지 않으며, 사이트 저장 공간을 지우면 사라질 수 있습니다.
- 다른 참가자의 점수나 실시간 순위 기능은 없습니다.

## 3. 테스트 체크리스트
- [ ] Vercel 배포 주소에서 웹앱이 열리는지 확인
- [ ] 별명을 입력하고 퀴즈를 시작할 수 있는지 확인
- [ ] 정답과 오답에 따라 점수가 올바르게 계산되는지 확인
- [ ] 새로고침 후 같은 별명으로 진행 기록이 복원되는지 확인
- [ ] 30문제 완료 후 최종 점수와 처음부터 다시 하기 버튼을 확인
- [ ] 개발자 도구의 Network 탭에서 Firebase/Firestore 요청이 없는지 확인

## 참고
점수 계산은 브라우저 안에서 이루어집니다. 개인 학습용으로는 간편하지만, 개발자 도구를 이용해 기록을 조작하는 것을 방지하는 서버 측 보안은 제공하지 않습니다.
